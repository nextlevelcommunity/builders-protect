# Roadmap

## Disponível

- App macOS com varredura, agendamento local e notificações.
- CLI para macOS, Linux e Windows.
- GitHub Action com resumo, JSON e SARIF.
- Rotinas diárias, semanais e mensais via cron.
- Diagnóstico com IA para assinantes no app.

## Em preparação

- Red Teaming opt-in no app, após estabilização do consumo de recursos.
- Interface desktop para Windows e Linux.
- Build macOS assinado e notarizado.
- Checksums e artefatos de release para todas as plataformas suportadas.

## Avaliação

- Mais ecossistemas de lockfile.
- Regras de priorização por criticidade e exposição.
- Integração com outros fluxos de CI.
- Relatórios comparativos entre execuções.

## Fora do escopo atual

- Correção automática de dependências.
- Pentest ou análise de infraestrutura.
- Substituição de revisão de código.
- Interface desktop Windows/Linux nesta versão.

Datas não são compromissos públicos. A ordem pode mudar conforme risco, feedback e estabilidade.
